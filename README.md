A Node program that writes one short poem about agency — the power to choose and to act, and what passes between two agents that agree on one plan — to `/output/entry.txt`. Entry for the make.fun bounty "The poem about two agents agreeing".

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
